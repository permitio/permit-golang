# Public methods that the cloud lane cannot call, each with the reason and the phase of the local
# harness that proves it instead. TestE2ESurfaceComplete (completeness_test.go) checks that every
# method of testdata/operation-map.json is in exactly one end-to-end state; a line of a method
# that a cloud scenario covers is stale and fails the gate. A release accepts a line only when the
# harness evidence lists its phase as passed (tools/cmd/releasecheck validate).
#
# One method per line: <Type>.<Method> <reason> <phase>, such as
# ProjectsService.List org-key api.projects. The reason is one of:
#
#   org-key              it needs an organization-level API key, which the cloud lane does not
#                        have (keys.yaml)
#   account-level-write  it writes to the account, outside the run's scratch environment
#   needs-pdp-id         it needs the ID of a PDP of the account
#   unverified-response  the cloud lane cannot check its reply, such as one that waits for audit
#                        logs to be ingested
#
# Blank lines and lines that start with # are ignored.
