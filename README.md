# Go SDK for Permit.io

## Status

This branch holds v2 of the SDK, the module `github.com/permitio/permit-golang/v2`. v2 is under
development and is not released.

If you use v1, the module `github.com/permitio/permit-golang`, stay on v1.3.x. v1 is maintained on
the [`release/v1`](https://github.com/permitio/permit-golang/tree/release/v1) branch.
