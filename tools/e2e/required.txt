# Tests that must run and pass in every run of the end-to-end scenarios against the PDP container,
# dry or live, such as the legs pinned and latest. The jobs e2e and e2e-latest of ci.yml check
# them with checkgotest -require-file (tools/cmd/checkgotest). A run selects the scenarios of
# every PDP and those of the PDP that its clients call, so the scenario of the cloud PDP, which
# runs on the leg cloudpdp only, is not here: tools/e2e/required-cloudpdp.txt lists it for that
# leg, and the offline test job requires it in the dry run, which runs every scenario
# (.github/required-tests.txt). TestRequiredScenarios checks that this file names the subtest of
# each scenario that such a run selects, and of no other, and that tools/e2e/required-cloudpdp.txt
# names the same tests outside the subtests of TestCloud. One test per line: its package import
# path and its name, separated by a space. Blank lines and lines that start with # are ignored.
